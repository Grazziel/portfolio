# Portfolio — Graziele Gomes de Macedo

Mi portfolio web personal: quién soy, los proyectos que he construido y cómo contactarme. Disponible en español e inglés.

## Tecnologías

- React + TypeScript
- Vite
- CSS propio
- Devicon para los iconos de tecnologías

## Secciones

- **Sobre mí**: mi camino de Administración y Finanzas a desarrollo Full-Stack.
- **Proyectos**: proyectos del bootcamp Full-Stack de 4Geeks Academy.
- **Habilidades**: las herramientas con las que trabajo.
- **Contacto**: email y LinkedIn.

## Ejecutarlo en local

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
